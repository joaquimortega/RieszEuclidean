# Metadata schema

`formalization-v0.4.schema.json` is an unmodified copy of the official schema:
https://raw.githubusercontent.com/mathlib-initiative/formalization.yaml/main/schema/v0.4.schema.json

It was retrieved on 2026-09-13. Vendoring the schema makes validation independent
of network access and future upstream changes. Install requirements-validation.txt
and run python3 scripts/check_metadata.py from a standalone clone.
